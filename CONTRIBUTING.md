# Contributing to jsonapi-nano

First off, thank you for considering contributing to `jsonapi-nano`! It's contributors like you that keep open-source tools fast, reliable, and accessible.

## How Can I Help?

### 🐛 Reporting Bugs

- Search the issue tracker to ensure the bug hasn't been reported yet.
- Open a new issue with a clear title, reproducible steps, and environment details (Node.js version, framework used).

### 💡 Suggesting Enhancements

- Open an issue describing the feature you'd like to see and your specific use case. We want to keep the core library 100% dependency-free and lightweight!
